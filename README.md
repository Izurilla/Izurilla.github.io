# Izurilla.github.io
Web oficial de Irene Zurilla.

## Mantenimiento de contenidos
La web está construida como sitio estático en GitHub Pages. Para los cambios habituales no hace falta rehacerla: basta con actualizar los textos o los datos correspondientes.

### Forma recomendada
Irene puede enviar el cambio directamente en ChatGPT, por ejemplo:

- `Cambia en Sobre mí este párrafo por: ...`
- `En Libros actualiza el estado de El libro mágico de Hugo e Inés a: ...`
- `Publica esta nota en el Cuaderno: ...`

ChatGPT puede aplicar el cambio en este repositorio conectado y GitHub Pages publicará la nueva versión.

## Cuaderno de autora
Las entradas públicas del diario se guardan en `cuaderno-data.js`.

Cada entrada sigue esta estructura:

```js
{
  date: "2026-09-15",
  title: "Título de la entrada",
  project: "Proyecto o categoría",
  status: "En proceso",
  text: "Texto de la entrada"
}
```

La web ordena automáticamente las entradas por fecha. Las más recientes aparecen primero en `Cuaderno`.

Para publicar una entrada desde ChatGPT no es obligatorio usar esta estructura: Irene puede mandar el texto de forma natural y se prepara la ficha antes de publicarla.

## Pendientes de contenido definitivo
La estructura visual y técnica está montada. Quedan por incorporar cuando estén disponibles o aprobados para uso público:

- correo profesional definitivo;
- enlaces oficiales a redes sociales;
- fotografías de autora seleccionadas;
- cubierta/recursos definitivos de los libros;
- dossier de autora descargable;
- dominio propio, si se contrata más adelante.
